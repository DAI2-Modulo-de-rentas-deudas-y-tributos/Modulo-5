# SCRUM-793 — Auditoría SCA de dependencias Spring

Fecha: 2026-10-28

Base auditada: `add645d9f98f4242abf290c5b182b553da33f573`

Alcance: árbol Maven backend; CVE-2025-41248, CVE-2025-41249, CVE-2026-47834 y CVE-2026-47860.

## Cambio aplicado

Se actualizó únicamente el parent Spring Boot de `3.5.5` a `3.5.16`, último parche OSS estable de la línea 3.5 observado en la auditoría. `springdoc-openapi-starter-webmvc-ui` se mantiene fijado directamente en `2.8.9`.

### Estado de soporte de la línea 3.5

Spring Boot `3.5.16` es el último release OSS de la generación `3.5.x`; Spring recomienda pasar a `4.0.x` o `4.1.x` para seguir recibiendo soporte OSS. Esto marca el fin de las publicaciones OSS nuevas de la rama 3.5, pero no elimina la opción de soporte comercial para quienes deban permanecer en ella. La actualización aplicada resuelve los avisos de 2025 dentro del BOM 3.5; no convierte la línea en una rama con nuevos fixes OSS ni resuelve por sí sola los CVE-2026-47834/47860.

En la base, Maven resolvía Spring Security `6.5.3`, Spring Framework `6.2.10`, Spring Data JPA `3.5.3` y Spring AMQP/Rabbit `3.2.6`. Tras la actualización, el árbol resuelto queda en:

| Artefacto | Declaración | Antes | Después |
|---|---|---:|---:|
| `spring-boot-starter-parent` | parent directo | 3.5.5 | 3.5.16 |
| `springdoc-openapi-starter-webmvc-ui` | dependencia directa | 2.8.9 | 2.8.9 |
| `spring-security-config`, `spring-security-web`, `spring-security-core` | transitivas de starter-security | 6.5.3 | 6.5.11 |
| módulos Spring Framework (incluye `spring-webmvc`) | transitivas de starters | 6.2.10 | 6.2.19 |
| `spring-data-jpa` | transitiva de starter-data-jpa | 3.5.3 | 3.5.13 |
| `spring-amqp`, `spring-rabbit` | transitivas de starter-amqp | 3.2.6 | 3.2.12 |

Los avisos CVE-2025 describen problemas de detección de anotaciones en supertipos genéricos no acotados con decisiones de autorización. Los avisos CVE-2026 describen una condición de `Sort` no confiable contra consultas nativas con sintaxis SQL no ASCII, y descompresión ilimitada de cuerpos comprimidos que un atacante pueda publicar en una cola consumida con descompresión habilitada, respectivamente.

### Resumen de opciones y criterio de actualización

- La corrección común de Jackson para los avisos inventariados está incluida en la misma línea 2.21; el POM fija el BOM en 2.21.8. El árbol post-cambio confirma que `jackson-core` y `jackson-databind` resuelven a 2.21.8.
- Los cuatro avisos Tomcat tienen corrección efectiva desde 10.1.59. El POM fija `tomcat.version` en 10.1.61 y el árbol confirma `tomcat-embed-core:10.1.61`, manteniéndose en la línea 10.1 / Servlet 6.
- Para `amqp-client`, el menor arreglo depende del advisory; el POM fija 5.36.0 y el árbol confirma esa versión. Cubre nueve de los diez IDs enumerados; GHSA-cqgh-8p3p-mx4m requiere 5.36.1 y sigue pendiente. El broker externo no se habilitó ni se probó.
- `postgresql` tiene un arreglo en 42.7.12 para CVE-2026-54291; el POM fija 42.7.14, que también incorpora fixes posteriores. El árbol confirma `org.postgresql:postgresql:42.7.14` en runtime.
- `commons-compress` es test-only; Commons Lang y Log4j son transitivas runtime, pero las APIs/precondiciones de los advisories correspondientes no se encontraron en M5. La falta de precondiciones locales no se usa para declarar el componente libre de riesgo.

### Discrepancia de severidad y aplicabilidad de Spring MVC

Para los dos advisory `spring-webmvc` del inventario, OSV/GHSA etiqueta `CVE-2026-47884` y `CVE-2026-47890` como `CRITICAL`, mientras que los avisos primarios de Spring clasifican esos CVE como `MEDIUM` y `LOW`, respectivamente. El inventario conserva las etiquetas reportadas por OSV; para evaluación del proveedor se consignan también las severidades de Spring.

- `CVE-2026-47884` requiere `XsltView` y un mapeo `/**` que renderice una vista sin nombre de vista especificado. El código de M5 no declara `XsltView`, `ViewResolver` ni `ModelAndView`; los controladores web son `@RestController` con rutas API explícitas, sin mapeo MVC catch-all `/**`. Los comodines `/**` encontrados en configuración CORS/seguridad no son mapeos de controladores y no satisfacen por sí mismos esa precondición.
- `CVE-2026-47890` requiere fragmentos de vista enviados a clientes por Server-Sent Events y datos controlables por atacante. No se encontraron `ServerSentEvent`, `SseEmitter`, `text/event-stream`, fragmentos de vista ni un `ViewResolver` configurado en el código.

Por estas búsquedas, no se identifican las precondiciones de explotación de esos dos avisos en M5. La dependencia resuelta `spring-webmvc:6.2.19` permanece dentro del rango afectado; esto es evaluación de aplicabilidad del código, no una actualización ni resolución del CVE. El aviso de Spring indica 6.2.20 como Enterprise Support Only y 7.0.9 como OSS; no se aplicó un override fuera del BOM Boot 3.5.

- Boot 3.5.16 corrige los CVE-2025-41248/41249 encontrados en las versiones resueltas por la base.
- Boot 3.5.16 todavía administra Spring Data JPA 3.5.13 y Spring AMQP 3.2.12, dentro de los rangos afectados de CVE-2026-47834/47860. No se cambiaron estas versiones ni se adoptó Boot 4; se requiere decisión del equipo sobre soporte Enterprise o migración futura compatible.
- El triage inicial se complementa con el scan final. OSV ya no reporta los advisories de Jackson, Tomcat, pgJDBC ni Netty en las versiones efectivas. Permanecen en el scan los 7 findings de Rabbit 5.36.0, Commons Compress 1.24.0 (test), Commons Lang 3.17.0, Log4j API 2.24.3 y Spring MVC 6.2.19. Además Spring Data JPA 3.5.13 y Spring AMQP 3.2.12 conservan avisos verificados directamente con Spring. `clean verify` pasó 565 tests y el gate JaCoCo; PIT final permanece bajo coordinación.
- La condición de compresión en el broker no fue verificada en Core/M9. No se probó entrega ni ACK externo.
- El árbol y las pruebas corresponden a la línea candidata de este ticket; no ejecutan migraciones sobre la base compartida `rentas`.
